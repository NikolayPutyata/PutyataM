# Проєкт: сайт weksar.com

## Контекст
- Сайт «Партнерське об'єднання Weksar» — послуги ліквідації ТОВ (Київ) та суміжні юридичні послуги (точний перелік — у Фазі 0 ROADMAP).
- Мета сайту: отримувати заявки від клієнтів з Google (SEO + Google Ads), згодом — ретаргетинг у Meta (Facebook/Instagram).
- Поточний стан: React-сайт, SEO не налаштоване, аналітики та рекламних кабінетів немає. План — перенести сайт на Next.js з новим дизайном і вбудованим SEO.
- Власник проєкту: Коля. Спілкування — українською, на «ти».

## Як працюємо
1. Детальний план — `docs/ROADMAP.md`. На початку кожної сесії прочитай розділ «Статус» нижче і останні записи «Журналу» в ROADMAP.
2. Працюємо фазами по порядку. Не переходь до наступної фази без підтвердження Колі. Результат кожної фази — файл у `docs/` (вказано в ROADMAP).
3. В кінці кожної сесії: онови «Статус» нижче і додай запис у «Журнал» ROADMAP (дата · що зроблено · що далі · відкриті питання до Колі).
4. Не вигадуй фактів про компанію: ціни, строки, кейси, відгуки, кількість клієнтів, реквізити, гарантії. Де даних немає — став плейсхолдер `[[ПОТРЕБУЄ ДАНИХ: що саме]]` і внеси питання в журнал.
5. Тексти — українською. Юридична термінологія — за законодавством України (ЦКУ, ГКУ, Закон «Про державну реєстрацію юридичних осіб, ФОП та громадських формувань» тощо), без калькованих американських термінів.
6. Великі зміни — в окремій гілці. Старий сайт не вимикаємо, поки не налаштовані й не перевірені 301-редиректи.
7. Ключі, ID лічильників, токени — тільки в `.env` / змінних середовища, ніколи в коді чи git.
8. Будь-яка дизайн-зміна не повинна погіршувати швидкість (Core Web Vitals). Перевіряй Lighthouse після значних змін.

## Чого Claude Code НЕ робить сам
Створення акаунтів Google/Meta, верифікації, оплата реклами, запуск кампаній — це робить Коля (або Claude у чаті через браузер з його підтвердженням). Claude Code готує код, тексти, файли з налаштуваннями і чекліст.
