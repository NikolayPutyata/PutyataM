# Як залити оновлення поточного сайту на фрихост

Стосується поточного сайту (Vite + React) до переїзду на Next.js.

## 1. Зібрати

На комп'ютері в папці проєкту:

```bash
git fetch origin
```
```bash
git checkout claude/new-session-5dqdlw
```
```bash
git pull
```
```bash
npm install
```
```bash
npm run build
```

Якщо вже є ID Google Tag Manager, перед `npm run build` створи в корені проєкту файл `.env.local` з рядком `VITE_GTM_ID=GTM-XXXXXXX`.

Після збірки з'явиться папка `dist/`.

## 2. Залити

Через файловий менеджер хостингу залий **увесь вміст** `dist/` у кореневу папку сайту weksar.com, із заміною файлів.

⚠️ **Приховані файли.** У збірці є два файли, назви яких починаються з крапки:
- `dist/.htaccess` → у корінь сайту;
- `dist/assets/.htaccess` → у папку `assets/` на хостингу.

У Windows вони можуть бути не видні: Провідник → «Вигляд» → «Показати» → «Приховані елементи».

**Якщо на хостингу вже є свій `.htaccess`** у корені сайту, спершу відкрий його і надішли мені вміст. Не перезаписуй, доки я не перевірю: там можуть бути налаштування, яких немає в нашому файлі.

Старі файли з `assets/` (з іншими назвами) можна не видаляти, вони нікому не заважають.

## 3. `weksar.com.ua`

Щоб `weksar.com.ua` перенаправляв на `weksar.com`, у панелі фрихосту прив'яжи `weksar.com.ua` (і `www.weksar.com.ua`) **до того самого сайту**, що й `weksar.com`, як синонім (alias). Далі редирект зробить наш `.htaccess`, зі збереженням адреси сторінки.

Якщо `.ua`-домен у іншого реєстратора чи хостингу, налаштуй там переадресацію 301 на `https://weksar.com`. Або напиши мені, де він, і я підкажу.

## 4. Перевірити після заливки (5 хвилин)

| Відкрий | Має бути |
|---|---|
| `https://weksar.com/robots.txt` | текст `User-agent: *…`, а не сайт |
| `https://weksar.com/sitemap.xml` | XML зі списком адрес |
| `https://weksar.com/services/liquidation` | сторінка ліквідації |
| `https://weksar.com/qwerty` | сторінка «Сторінку не знайдено» |
| `https://www.weksar.com/contacts` | адреса в браузері змінюється на `https://weksar.com/contacts` |
| `http://weksar.com` | адреса змінюється на `https://…`. Якщо ні, увімкни в панелі фрихосту перенаправлення на HTTPS або напиши мені |
| `https://weksar.com.ua` | перекидає на `https://weksar.com` (після кроку 3) |

**Тестова заявка:** відкрий `https://weksar.com/services/liquidation?utm_source=test_a&utm_campaign=test_b`, натисни «Ліквідувати ТОВ», заповни форму. У Telegram мають прийти рядки «Сторінка», «Кнопка», «Джерело».

**Якщо щось зламалося:** видали `.htaccess` з кореня сайту через файловий менеджер. Сайт повернеться до попередньої поведінки, а ти напиши мені, що саме сталося.
