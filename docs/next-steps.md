## Крок 2. Сервер заявок — 1–2 дні роботи Claude + 30 хвилин Колі

Зараз форми не можуть відправити заявку (сервер `unium-server` не відповідає), тому пропонують WhatsApp. Це головна дірка: реклама без робочої форми — злитий бюджет.

**Що Claude зробить у репозиторії `NikolayPutyata/server` перед заливкою:**
- Новий маршрут `POST /leads`: сайт надсилає дані окремими полями (ім'я, телефон, питання, сторінка, мова, UTM, джерело), сервер сам перевіряє і форматує повідомлення в Telegram.
- Перевірка даних (формат телефону, довжина полів), захист від спаму: honeypot, обмеження частоти запитів з однієї IP-адреси, ліміт розміру запиту. За потреби пізніше — Cloudflare Turnstile.
- CORS лише для дозволених сайтів (зараз відкритий для всіх).
- Повтор відправки в Telegram при збої; зрозуміла відповідь сайту, щоб форма показувала WhatsApp лише тоді, коли заявка справді не дійшла.
- Логи без персональних даних (без імен і телефонів).
- Старий маршрут `POST /telegram/send` лишається без змін — щоб не зламати інший сайт, якщо він ним користується (у коді є згадка про `unium.com.ua`).
- Автотести, README з інструкцією запуску.
- На сайті: форма переходить на `/leads`; перевірка «від заявки до Telegram» разом із Колею.
- Пізніше (крок 6): серверна подія «Lead» для Meta (Conversions API) — саме на цьому сервері, бо сайт статичний.

**Від Колі:**
- [ ] Дати Claude доступ на запис до репозиторію `NikolayPutyata/server` (Claude GitHub App на цьому репозиторії). Скажи «даю доступ» — я запитаю його через інструмент, а ти підтвердиш.
- [ ] Відповісти: де і як запущений сервер (DigitalOcean App Platform? чи оновлюється автоматично з GitHub?) і **чи користується ним ще якийсь сайт** (unium.com.ua?).
- [ ] Самому вписати в налаштуваннях DigitalOcean змінні `TELEGRAM_BOT_TOKEN` і `CHAT_ID` (**не надсилати їх у чат**) і запустити застосунок, коли я скажу, що код готовий.
- [ ] Надіслати тестову заявку з сайту і підтвердити, що вона прийшла в Telegram.

## Крок 3. Акаунти Google (Фаза 0, що лишилась) — ~1 година Колі + очікування верифікацій

Покрокові інструкції — `docs/accounts-setup.md`. Можна зробити разом зі мною в чаті через браузер.

**Від Колі:**
- [ ] Google-акаунт для бізнесу (на нього все інше).
- [ ] **Search Console:** ресурс «Домен» `weksar.com`, підтвердження TXT-записом у реєстратора домену.
- [ ] **Google Analytics 4:** ресурс, потік даних для weksar.com → надіслати мені ID `G-…`.
- [ ] **Google Tag Manager:** контейнер «Веб» → надіслати мені ID `GTM-…` (ці ID не секретні — вони й так видно в коді сторінки).
- [ ] **Google Business Profile:** створити (без адреси офісу — «зона обслуговування»), пройти верифікацію (відео або листівка — кілька днів).
- [ ] Email для сайту, Політики конфіденційності і GBP.

**Claude:**
- Готовий файл налаштувань GTM для імпорту (GA4 + події `generate_lead`, `click_phone`, `click_messenger`, `click_email` — вони вже відправляються з сайту), інструкція «Імпорт → Опублікувати».
- Збирає сайт з `GTM-…` (ID — у `.env.local`, не в git) і дає новий архів.
- Тексти для GBP: опис, категорії, список послуг з цінами, зона обслуговування (`docs/gbp.md`).

## Крок 5. Google Ads (Фаза 6.1) — старт через ~1 тиждень після кроків 2–4

Без робочої форми (крок 2) і аналітики (крок 3) рекламу не запускаємо: не буде видно, скільки коштує заявка.

**Від Колі:**
- [ ] Акаунт Google Ads (у «режимі експерта», без автоматичної кампанії), верифікація рекламодавця (документи ФОП), спосіб оплати.
- [ ] Keyword Planner: завантажити `docs/keywords-for-planner.txt` → «Отримати обсяг пошуку і прогнози» → експорт CSV мені.
- [ ] Рішення про денний бюджет на тест (запропоную за даними Keyword Planner).
- [ ] Створити кампанію за планом (або разом зі мною в браузері) і запустити.

**Claude:** `docs/ads/google-ads-plan.md`:
- кампанії за 4 напрямами (ліквідація ТОВ, реєстрація, тендери, ліцензії) — окремі бюджети;
- групи оголошень → конкретні сторінки послуг; ключові слова (фразова і точна відповідність);
- мінус-слова; 2–3 адаптивні оголошення на групу; розширення (дзвінок, уточнення, посилання);
- UTM-шаблон, конверсія `generate_lead` з GA4; без «гарантій» і обіцянок (Закон «Про рекламу», правила Google).

**Далі:** тест 2–4 тижні; раз на тиждень Коля надсилає звіт (пошукові запити, витрати, конверсії), Claude — мінус-слова, ставки, нові оголошення. Головна метрика — ціна заявки.

## Короткий список «від Колі» за порядком

1. Залити останній `weksar-site.zip`, прив'язати `weksar.com.ua`, увімкнути HTTPS.
2. Доступ до репозиторію сервера + відповіді: де запущений, чи ним користується інший сайт.
3. Google-акаунт → Search Console, GA4, GTM (надіслати `G-…` і `GTM-…`), Google Business Profile.
4. Email, ПІБ і РНОКПП ФОП, строк зберігання заявок.
5. Ключові токени (`TELEGRAM_BOT_TOKEN`, `CHAT_ID`) — лише в налаштуваннях DigitalOcean, не в чаті.
6. Перед рекламою: акаунт Google Ads, верифікація, оплата, експорт з Keyword Planner, бюджет.
