# weksar.com — новий сайт (Next.js)

Статичний сайт: `npm run build` створює папку `out/` з готовими HTML-сторінками, яку можна залити на будь-який хостинг (фрихост, Apache).

```bash
npm install
npm run dev      # локально: http://localhost:3000
npm run build    # збірка в out/
```

Змінні середовища — у `.env.local` (зразок у `.env.example`). Дизайн-система: `../docs/design-system.md`. Структура сторінок: `../docs/seo-structure.md`.
